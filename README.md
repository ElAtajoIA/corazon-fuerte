# Corazón Fuerte (espejo en GitHub Pages)

App gratuita, sin instalar y sin cuenta, para personas tras un infarto o con insuficiencia cardiaca con marcapasos o desfibrilador: paseos con tabla BORG, registro de tensión y pulso, pastillero, semáforo de alimentación, protocolo de dolor torácico e informe para el médico.

La casa principal de la app es https://corazon-fuerte.pages.dev/ — este repositorio es solo su espejo en GitHub Pages, por si la principal no cargara.

Los datos de cada persona se guardan en su propio Google Drive y solo en su navegador; nadie más tiene acceso a ellos.
